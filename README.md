# CV Studio — Professional CV & Resume Builder SaaS

Nền tảng tạo, chỉnh sửa và xuất CV chuyên nghiệp với **14 mẫu giao diện chuẩn ATS**, bộ chuẩn hóa danh pháp công nghệ **Tech Linter**, công cụ phân tích độ khớp mô tả công việc **JD Matcher**, mã QR cá nhân động và thanh trượt tùy biến kích thước lề/chữ chi tiết.

Phát triển trên nền tảng **Next.js 14 (App Router) + TypeScript + Tailwind CSS**.

---

## 🌟 Tính năng nổi bật

### 1. 14 Mẫu CV Chuẩn ATS & Đa Dạng Phong Cách
- **Nhóm Popular & Hiện đại:** Rabbit (chuẩn Tech Lead), Chicken, Decker.
- **Nhóm ATS Tối Giản:** Minimalist, Classic ATS, Corporate Clean.
- **Nhóm Sáng Tạo & Sidebar:** Elegant Sidebar, Split Creative, Executive.

### 2. Bộ Chuẩn Hóa Danh Pháp Công Nghệ Tự Động (Tech Linter)
- Tự động phát hiện và sửa các lỗi viết hoa/thường không chuẩn của **120+ công nghệ** theo quy chuẩn thương hiệu quốc tế (`Node.js`, `TypeScript`, `Next.js`, `Tailwind CSS`, `GitHub`, `RESTful API`...).
- Chế độ **Chuẩn hóa tất cả 1 chạm** hoặc sửa từng lỗi riêng biệt.
- Tự động thu gọn và làm sạch chuỗi lặp (De-stuttering engine).

### 3. Phân Tích Độ Khớp JD & Gợi Ý Từ Khóa (JD Matcher)
- Dán bất kỳ bản mô tả công việc (JD) nào để AI quét độ khớp điểm số ATS (0 — 100%).
- Liệt kê từ khóa đã có và từ khóa còn thiếu, cho phép thêm từ khóa vào mục Kỹ năng chỉ với 1 cú click.

### 4. Thanh Trượt Tùy Biến Lề & Kích Thước Chi Tiết (Fine-grain Typography Sliders)
- 7 thanh trượt vi chỉnh độc lập: Cỡ chữ họ tên, tiêu đề mục, nội dung, lề trên/dưới, lề trái/phải, khoảng cách giữa các mục và các thẻ.
- 3 bộ Preset nhanh: **Cân bằng (Mặc định)**, **Gọn 1 trang (A4 1-Page Compact)**, **Rộng rãi (Spacious)**.

### 5. Mã QR Cá Nhân Động (Dynamic QR Code)
- Tự động tạo mã QR dẫn tới LinkedIn, GitHub, Website hoặc lưu danh thiếp vCard vào danh bạ điện thoại của nhà tuyển dụng.
- Tùy biến vị trí (Header, Footer, Sidebar) và bảng màu.

### 6. Đa Ngôn Ngữ & Đa Phiên Bản CV
- Hỗ trợ chuyển đổi song ngữ tức thì: **Tiếng Việt ⟷ Tiếng Anh**.
- Quản lý đồng thời nhiều phiên bản CV (Frontend, Fullstack, Tech Lead...) trong cùng một tài khoản.
- Tính năng **Trang Web Xem Trực Tuyến Công Khai (Public Shareable Web View)** với chế độ bảo mật số điện thoại / địa chỉ.

### 7. Xuất Bản Đa Định Dạng
- Xuất file **PDF chất lượng cao (A4)** in ấn chuẩn xác.
- Xuất ảnh **PNG / JPEG độ phân giải siêu nét (1x, 2x, 3x Retina)**.
- Xuất / Nhập file **JSON dự phòng** để chuyển đổi giữa các thiết bị.

## 💻 Khởi chạy và Phát triển Local

```bash
# 1. Cài đặt thư viện (nếu clone lần đầu)
npm install

# 2. Khởi chạy Development Server (Cổng 3001)
npm run dev

# 3. Mở trên trình duyệt
http://localhost:3001
```
